# 计算机科学与技术 · 本科互动学习站（打包版）

一个**零依赖、完全离线**的计算机专业本科自学程序：双击就能在浏览器里按培养方案学习，
包含讲解、可运行的代码示例、可以在页面上单步跑的交互实验、随堂测验与错题本。
学习进度自动保存在浏览器本地。

**这个包不需要安装任何东西，也不需要联网。** 里面没有 `node_modules`，没有 CDN 外链，
数学公式用的 KaTeX（含 20 个字体文件）已经放在 `cs/vendor/katex/` 里。

---

## 怎么打开

**方式一（最简单）**：双击 `cs\index.html` —— 全部功能可用，公式照常渲染。

**方式二（推荐）**：双击本目录下的 `start.cmd` —— 会在 `http://127.0.0.1:8123/cs/index.html` 起一个本地服务器并自动打开浏览器。

> `start.cmd` 会自动找 node → 找 python → **两个都没有就直接打开 `cs\index.html`**，
> 所以没装 Node.js 的电脑上双击它也一样能用。

**方式三**：只想要这个站，进入 `cs\` 目录双击 `start.cmd` 也可以（它按上级目录定位，别把 `cs` 文件夹改名）。

### 手机 / 平板也能看（同一个 WiFi）

`start.cmd` **默认已打开局域网访问**，启动后窗口里会打印手机能打开的地址：

```
  手机 / 平板（需与本机连同一个 WiFi）:
    http://192.168.0.109:8123/cs/index.html   [WLAN]
```

在手机浏览器里输入这一行即可（IP 用你自己窗口里显示的那个）。注意三点：

- 手机和电脑要连**同一个 WiFi**；有些路由器开了"AP 隔离"会挡住，换个网络、或用电脑连手机热点即可。
- 第一次连接时 **Windows 防火墙可能弹窗**，选"允许访问"（专用网络）。
- **同一 WiFi 下的其他设备也能访问**，所以只在可信网络里开；关掉那个黑色窗口就没人能访问了。

只想要本机访问（更安全）：跑 `node cs\tools\serve.mjs 8123 --root .`（不加 `--lan` 就只监听本机），或直接双击 `cs\index.html`。

### 手机和电脑的进度是共用的

通过 `start.cmd`（本地服务器）打开时，进度会自动同步到电脑上 `cs\.progress\` 里的一个 json 文件，
**手机和电脑看到的是同一份进度** —— 在手机上刷的题、标"已掌握"的讲，切回电脑就有。

- 顶栏右侧有个**状态点**：绿色「已同步」= 正在同步；灰色「仅本机」= 没连上服务器（或你是直接双击 `index.html` 打开的）。点它可以手动再同步一次。
- **打开页面时**自动把"本地那份"和"服务器那份"按讲次/按题合并（取较新的记录，计数只增不减），所以在手机上学 A 课、电脑上学 B 课，两边最后都全。
- **每次答题先写本地再推送**；连不上服务器就静默退回纯本地，不弹错误、不影响学习。
- 直接双击 `cs\index.html`（`file://`）时没有服务器，进度只存在那台设备上 —— 功能完全一样，只是不跨设备。
- 「💾 数据」导出/导入 JSON 的通道一直保留，可用于备份或手动搬运。

## 里面有什么

| 目录 | 内容 |
| --- | --- |
| `cs/index.html` | 站点入口 |

## 不需要，但可以跑的质量检查（要 Node.js）

```powershell
cd cs
node tools/validate-curriculum.mjs     # 结构、id、实验配置、题目格式
node tools/smoke-test.mjs              # 模拟浏览器渲染每一讲、运行每个实验
node tools/audit-math.mjs              # 公式体检：每段 $...$ 用 KaTeX 真渲染一遍
node tools/check-code.mjs              # C 代码块真实编译（需要 gcc）
node tools/check-python.mjs            # Python 代码块真实执行（需要 python）
powershell -File tools\verify-browser.ps1   # 无头 Edge 真实渲染并断言 DOM
```

这些命令都是**可选的**：不跑它们，站点照样正常使用。

## 几点说明

- **进度存在浏览器里**（localStorage，键名 `cs-learn:v1`）。清理浏览器数据会丢，
  页面右上角「💾 数据」可以导出/导入 JSON 备份。
- **建议固定用同一种打开方式**：`http://127.0.0.1:8123` 与 `file://` 在浏览器眼里是两个不同来源，
  进度不互通。
- 想换端口：`node cs\tools\serve.mjs 8125 --root .`
- 零基础怎么用：首页顶部「完全零基础？按这个顺序开始」→ 第 0 课；
  左侧「📖 术语表」可搜索，正文里的术语是虚线下划线，点一下弹出解释。
