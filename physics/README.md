# 物理学 · 本科互动学习站

一个**零依赖、离线可用**的物理学本科自学程序：双击 `index.html` 就能在浏览器里按培养方案学习，
包含物理图像与推导讲解、**可拖动参数的数值仿真实验**、随堂测验与错题本、SM-2 间隔重复闪卡、
公式与常量速查；学习进度自动保存在本地，也能在手机与电脑之间同步。

> 面向：想系统学物理学本科主干的人（在校生、跨专业自学者、想补物理图像与估算能力的人）。
> 编排原则：**物理图像 → 定量表述 → 推导 → 量纲与数量级 → 仿真验证 → 失效边界**，六步缺一不可。

## 1. 快速开始

| 方式 | 怎么做 | 打开的地址 |
|---|---|---|
| A（最简单） | 双击 `index.html` | `file://` 直接用，全部功能离线可用 |
| B（推荐） | 双击 `start-physics.cmd` | `http://127.0.0.1:8125/index.html` |
| C（四个站一起） | 双击上一级目录的 `start-all.cmd` | `http://127.0.0.1:8125/index.html` |

> `start-physics.cmd` 内部只写 ASCII 英文提示：cmd.exe 按字节解析批处理，中文容易把命令行撕裂
> （会出现 `'evel' 不是内部或外部命令` 这类报错）。中文说明以本文件为准。

**手机 / 平板**：用 `start-physics.cmd` 打开时，窗口里会打印局域网地址（形如
`http://192.168.x.x:8125/index.html`），手机连同一个 WiFi 就能打开，且与电脑共用同一份进度
（存在上一级目录的 `.progress/physics-learn_v1.json`）。需要注意的防火墙、AP 隔离等问题见
上一级目录的 `README.md`。

## 2. 为什么它和"看视频课"不一样

| 工具 | 练什么 |
|---|---|
| 🧪 **simlab 数值仿真** | 每个实验都能**拖动滑块改参数**，实时看到曲线、相图、能量条怎么变。物理不靠"记住结论"，靠"调一下看看会怎样"。 |
| 📐 **公式与常量速查** | 全部公式来自正文的 `formula` 块（不会出现"课本改了速查表没改"），每条都带 **单位** 与 **成立条件**——后两项才是物理公式最容易被忽略的部分。 |
| 🔢 **CODATA 常量表** | 值 + 单位 + 不确定度 + 量级参照。物理题算不对，一半原因是常量代错。 |
| 🃏 **闪卡（SM-2 间隔重复）** | 公式、常量与量级、定律的成立条件、单位换算——这些必须张口就来，按"快要忘记时再考一次"的节奏排给你。 |
| 🧮 **带机器复核的手算演练** | `calc` 块里的数值由 `tools/verify-numbers.mjs` 独立重算，**数写错会在质量门里报错**。 |
| 📕 **错题本 + 智能复习** | 答错自动进错题本，复习优先抽错题与正确率低的课。 |
| 📄 **学习报告** | 一键导出 Markdown：进度、错题、自检、下一步建议。 |

### 门禁的**能力边界**（哪几道是真门禁，哪几道只是分诊工具）

一次**独立审计**（由未参与建设的审计员用自写脚本复核）指出：**"全绿"这个说法曾经比实际覆盖面更大**。已按审计结论逐条修正，并把边界写清楚：

| 工具 | 性质 | 实际覆盖面 | 已知局限 |
|---|---|---|---|
| `validate-curriculum` / `smoke-test` / `verify-numbers` / `verify-simlab` / `check-python` / `audit-math` / `audit-content` / `coverage-check` / `test-mathrender` / `audit-constants` | **硬门禁**（退出码 1 = 失败） | 结构契约、数值、公式、代码块、覆盖度 | — |

**W7 终审抓到并修掉的真实缺陷（这一波的问题几乎全是"独立审计"抓出来的，不是站内工具）**

我请了**三位未参与建设的审计员**用自写脚本独立复核（内容、物理、工程各一位）。结论是：**内容与数值是真的扎实，但"全绿"曾经比实际覆盖面更大**。查出并处理的：

- **门禁形同虚设（最严重的一类）**：`audit-zero-basis.mjs` **永远 exit 0**——它打印出 16 处"首现未解释"，而外面那圈"13 个门禁全绿"的脚本照样把它算作通过；同时它只读 `md/title/note/items` 四个字段，**遗漏 116 万字符**（`outputs`/`quiz.why`/闪卡背面/实验面板说明）。现已改成扫全部可见字段，并明确降级为"分诊工具"（默认报告、`--strict` 才失败），因为它无法可靠判定"什么算解释"。
- **文档与工具直接矛盾**：README 曾写 `audit-zero-basis` "首现未解释 0"，而工具自己的输出是 16。已改为如实说明边界。
- **仿真读数错 1.65 倍**（审计员独立复算发现，站内 790 条自检全绿却没覆盖它）：`kinetic-gas` 的"峰值高度 f(v_p)"用了 `exp(-0.5)`，正确是 `exp(-1)`——默认参数下读数 0.003243 s/m，而**模型自己画出的曲线**峰值只有 1.9669e-3。同文件注释里的"不变量 4√π/e ≈ 2.608197"也是错的，正确是 4/(e√π) = 0.830215。
- **正文与自己的仿真相矛盾**：广义相对论讲引力波处写「df/dt = 45.4 Hz/s、t_c = 0.199 s」，而用**该条目自己给出的公式**算是 61.15 Hz/s、0.2146 s，站内 `gravity-wave` 模型也给 61.13/0.2147。两个正文数字彼此还不自洽。
- **其他确认缺陷**：`kepler` 在圆轨道（legend 点名的 r₀=1、v₀=1）处"周期（数值）"显示 0.00628（正确 6.28319，原因是 e=0 时靠"相邻极小值间距"定期）；`magnetization` 在默认 T=1（≥Tc）时"有效 β"显示 0，与同屏"β = 1/2"矛盾；`scattering` 的 info 说方势垒低能时 σ→0，实际 σ→4πa_eff² = 0.0675 fm²；`logistic` 在 r=4、x₀=0.5 时曲线塌成 0（info 部分披露、曲线通道没有）；`constants.js` 的 M☉ 与它自己注释里的 GM☉ **不能互相配合**（差 0.0257%），而库代码用的是 IAU 2015 值——三个来源混用。
- **前置知识倒置**：`有效数字` 在 13 门课里被当成已知常识使用（"保留三位有效数字"），却**从未在这些课里建立**；全站唯一的明文定义藏在《近代物理实验》的一个 note 里。
- **一处自相矛盾**：量子信息第 2 讲说"上一讲已经定义"列矢量与内积，而第 1 讲明说"本讲只用三样东西"且第 1 讲里没出现过"矩阵"。
- **工具盲区**：`audit-constants.mjs` 的判据是"前三位有效数字相同即认为在引用该常量"，**结构上发现不了第 4~5 位的分歧**（M☉ 就是这么漏掉的）。已在工具里记录该局限。

**W6 抓到并修掉的真实缺陷**

- **课程里的两处物理错误**（由模型作者对照自己的实现发现，我逐条复算后确认并改正）：
  - 《普通物理实验》说「把真截距改成 0.2，残差图会单调倾斜」——**错**。该模型的最小二乘**含截距项**，数据抬多高直线就跟多高，残差与横轴的相关系数恒为 0.000（实测三个取值都是 0.000）。已改写：残差倾斜只在「拟合模型比数据少一个参数」（例如强行让直线过原点）时出现，并把这一点讲成方法论提醒。
  - 《近代物理实验》说「没有拒斥电压时曲线会变成单调上升」——**错**。实扫 V_r = 0 / 1.5 / 5 V，局部极大数分别是 6 / 6 / 5，**峰一直在**；V_r 只砍掉低压段并压低电流。已改写任务，并把「曲线为什么有峰」与「电流为什么被压低」明确分成两件事。
- **`audit-math` 的一处误报**：新规则把 `\begin{pmatrix}0&-i\\i&0\end{pmatrix}` 里的矩阵换行 `\\i` 判成"反斜杠写多了"。已限缩为**只在非矩阵环境**做这条检查（矩阵换行后可以跟任何内容）。
- **一次工具链事故（自伤）**：我用 PowerShell 的 `Get-Content`/`Set-Content` 改 `verify-dom.mjs` 的阈值，结果同时加上 BOM 并把 51 行中文变成乱码（CP936 往返不可逆），文件报废。已整份重写，并**借机把它改成数据驱动**——不再给每一讲手写期望表，而是从 `data/*.js` 推出「应有几讲、几讲带仿真、几讲带代码块、共几条公式」，逐页契约改为统一断言。以后加课不用再维护那张表。
- 已把两条编码红线写进 `ZERO-BASIS-STANDARD.md` §7：`.ps1`/`.cmd` 必须纯 ASCII；**不要用 PowerShell 的 `Get-Content`/`Set-Content` 改 UTF-8 源码**（要改就用编辑工具，或显式指定 `UTF8Encoding($false)`）。

## 4. 每一讲长什么样

1. **学习目标**：一句话说明学完能做到什么。
2. **生活类比 / 几何直觉**：先建立"物理图像"，再上定量。
3. **核心讲解**：定量表述 + 公式四件套（意义 / 单位 / 成立条件 / 失效边界）。
4. **推导骨架**：用 `steps` 拆开，其中至少一步做**量纲检查**。
5. **🧪 交互仿真**：拖动参数实时看曲线，带"动手任务"与达成标准。
6. **手算演练**：给条件自己先算，再点「显示答案」核对（数值由工具独立复核过）。
7. **易错点**：单位、量纲、近似失效、把图像当证明——物理学最常翻车的地方。
8. **随堂测验 + 解析**：单选 / 多选 / 填空（含数值填空判分）/ 排序四种题型。
9. **闪卡**：本讲必须张口就来的公式、常量与量级。

## 7. 公式怎么写（KaTeX）

公式写在 `$...$`（行内）或 `$$...$$`（独立成行）里，由 **KaTeX** 渲染成出版级排版。
KaTeX 本体就在 `vendor/katex/`（约 520 KB，含 20 个字体文件），**不联网、不用 CDN**，
双击 `index.html` 走 `file://` 也能正常显示。万一该目录被删，`app/mathrender.js` 里的
纯 CSS 渲染器会自动兜底。

**在数据文件里写 LaTeX 必须用双反斜杠**：

```js
md: "$\\frac{1}{2}mv^2$"        // ✓ 正确
md: "$\frac{1}{2}mv^2$"         // ✗ `\f` 被 JS 吃掉，公式损坏
```

`node tools\fix-tex-escapes.mjs data\xxx.js --dry` 可以查这类损坏。
自检页：浏览器打开 `tools/formula-demo.html`。
