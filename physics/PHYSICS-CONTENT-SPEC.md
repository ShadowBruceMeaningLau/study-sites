# 物理站课程内容契约（PHYSICS-CONTENT-SPEC）

本文件是 `physics/data/*.js` 的**唯一格式与质量约定**。任何新增/修改课程都必须让
`node physics/tools/validate-curriculum.mjs` 全绿，并尽量让 `verify-simlab.mjs`、
`verify-numbers.mjs`、`audit-zero-basis.mjs`、`audit-independence.mjs` 都通过。

> 与数学站契约（`math/MATH-CONTENT-SPEC.md`）同源，**差别在 §3 的 simlab、§4 的 formula 块、
> §5 的物理特有要求**——物理的目标不是"证明"，而是**能从基本原理算出可与实验对账的数**。

---

## 1. 文件格式（硬性）

一个课程一个文件：`physics/data/<slug>.js`，**无 BOM 的 UTF-8**，内容**只有一条**
`window.COURSE_PACKS.push({...});` 对象字面量。

**禁止**：`import` / `export` / `require` / 函数 / 反引号模板字符串 / 正则字面量。
字符串里要写引号时用中文引号「」或单引号，不要用转义的双引号。

```js
window.COURSE_PACKS.push({
  id: "mechanics",                 // 与文件名一致，kebab-case
  title: "力学（普通物理）",
  icon: "🏃",                       // 1 个 emoji
  term: "大一上",                    // 建议修读时间
  hours: 96,                       // 建议学时（整数，>=8）
  blurb: "一句话说明这门课解决什么问题、为什么重要。",
  need: "学这门课之前需要会什么（1~3 句，见第 5 节自足性要求）。",
  tags: ["普通物理", "主干"],
  lessons: [ /* 见 §2 */ ],
  formulas: [ /* 可选：课程级公式，见 §4 */ ]
});
```

## 2. Lesson（讲）

```js
{
  id: "mech-newton-laws",          // 全局唯一，<课程前缀>-<短名>，同一门课前缀必须统一
  title: "牛顿三定律：从惯性到方程",
  goal: "学完后你能……（一句话，可检验）",
  est: 45,                         // 预计学习分钟数（5~240 的整数）
  blocks: [ /* 6~9 块，见下 */ ],
  quiz: [ /* 4~5 题 */ ],
  flashcards: [ /* 6~12 张，见 §6 */ ]
}
```

### 讲解块类型

| type | 必填字段 | 用途 |
|---|---|---|
| `analogy` | `title`, `md` | 生活/几何直觉。**每讲第一块建议用它** |
| `concept` | `title`, `md` | 核心讲解（物理图像 → 定量表述 → 适用边界） |
| `steps` | `title`, `items[]` | 推导骨架；`items` 可为字符串或 `{t,d}` |
| `formula` | `title`, `items:[{name,tex,note,units,condition}]` | 公式卡片（见 §4） |
| `calc` | `title`, `inputs:[{name,value}]`, `outputs:[]`, `verify?`, `note?` | 手算演练 |
| `code` | `lang`, `title`, `code` | `lang ∈ {python, c, text}`；物理课优先 python 数值实验 |
| `interactive` | `lab`, `title`, `config{...}` | 交互实验（见 §3） |
| `lab` | `title`, `steps[]`, `note?` | 纸笔/测量练习说明 |
| `pitfall` | `title`, `items[]` | 常见误区（量纲、单位、近似失效、把图像当证明） |

`md` 支持：`**粗体**`、`- 列表`、`> 提示`、`| 表格 |`、`$行内公式$`、`$$独立公式$$`。
**公式一律写进 `$...$`**，由 KaTeX 渲染（`audit-math.mjs` 会真渲染每一段）。

### 每讲推荐的块序（6~9 块）

```
analogy（直觉） → concept（核心） → formula（把结论写成公式）
→ steps（推导骨架） → calc（带 verify 的可算例子）
→ interactive（仿真验证） → pitfall（易错点） → concept（与实验/工程的联系）
```

## 3. `interactive` 与 simlab

**每门课至少 2 个 `interactive`**；物理站主力是 `simlab`。

### 3.1 simlab（推荐，仿真）

```js
{
  type: "interactive", lab: "simlab",
  title: "单摆：小角近似什么时候失效",
  config: {
    model: "pendulum",                     // 必须在 simlab-models-*.js 里已注册
    params: { L: 1, theta0: 30 },          // 覆盖默认参数（只需写要改的）
    plots: ["exact", "small"],             // 想画哪几条曲线（省略=模型默认）
    vary: [{ key: "theta0", label: "θ₀(度)", values: [10, 60, 120] }],  // 可选：多条对比曲线
    note: "先看 θ₀=10° 与 120° 的周期差异，再想为什么钟摆必须小角度。",
    tasks: [
      { t: "把 θ₀ 从 5° 调到 150°，记录周期比", hint: "看读数里的 T/T₀", check: "能说出 150° 时约大多少" },
      "把 L 改成 4 m，验证 T ∝ √L"
    ]
  }
}
```

**已注册模型（W1 波次）**：

| model | 说明 | 常用 params |
|---|---|---|
| `kinematics` | 匀变速直线运动 | `x0, v0, a, T` |
| `projectile` | 抛体运动（含阻力 k） | `v0, angle, k, g` |
| `collision` | 一维碰撞（动量/动能/恢复系数） | `m1, v1, m2, v2, e` |
| `rigid` | 刚体滚下斜面（转动惯量系数 β） | `theta, beta, g, T` |
| `shm` | 简谐振动（相图 + 能量条） | `k, m, x0, v0` |
| `damped-driven` | 阻尼受迫振动 + 共振曲线 | `m, k, b, F0, wd` |
| `pendulum` | 单摆（精确解 vs 小角近似） | `L, theta0, g` |
| `coupled` | 耦合振子（拍与简正模） | `m, k, kc, x1, x2` |
| `wave1d` | 弦上驻波（简正模、节点） | `L, v, n, A, t` |
| `kepler` | 万有引力轨道（开普勒定律） | `GM, r0, v0` |

后续波次的模型会陆续加入 `app/simlab-models-*.js`；写课程前先跑
`node tools/verify-simlab.mjs --list` 看当前有哪些可用。
**W2 的 17 个新模型（热学 / 电磁学 / 光学 / 原子物理）的完整契约见 §10。**

### 3.1.1 图表的两种模式（写 config 时用不到，写模型时必须知道）

`chart()` 支持两种横轴模式：

- **共享横轴**：给 `spec.x`，各条曲线只给 `y` —— 时间序列、分布曲线用它；
- **各自横轴**：曲线自带 `x`（`{x:[...], y:[...]}`）—— 电场线、能级图、多条轨迹、谱线用它。
  模型侧通过 `compute()` 返回的 `out.extra.lines = [{x, y, color, label, dash}]` 触发这个模式。

### 3.2 通用 lab（沿用数学站的组件）

`datalab`（逐步快照，`config.steps` ≥4 步）、`pathlab`、`pagelab`、`arbitlab`、`schedlab`、`cpulab`。
物理课用得最多的是 `datalab`：量级估算过程、误差合成、量纲检查步骤、实验数据处理流程。

## 4. `formula` 块与公式速查

```js
{
  type: "formula", title: "本章核心公式",
  items: [
    { name: "牛顿第二定律", tex: "\\vec{F} = m\\vec{a}",
      note: "力是改变运动状态的原因，不是维持运动的原因。",
      units: "F: N = kg·m/s²，m: kg，a: m/s²",
      condition: "惯性系；v ≪ c；质点模型" },
    { name: "万有引力", tex: "F = G\\dfrac{m_1 m_2}{r^2}",
      units: "F: N，m: kg，r: m",
      condition: "质点或球对称分布；r 为质心距离" }
  ]
}
```

**每条公式四件套缺一不可**：`tex` + `units`（单位/量纲）+ `condition`（成立条件）+ `note`（物理意义）。
**「成立条件」是物理公式最容易被忽略的部分，也是本站的检查重点**——不写会被 `audit-content.mjs` 点名。

这些条目会自动汇总到侧边栏「📐 公式与常量」页，**不需要另写一份速查表**。

## 5. 物理课特有的质量要求（会被抽查）

1. **每个公式四件套**：见 §4；正文里首次出现的公式也要给成立条件。
2. **数必须算对**：`calc` 块的数值结果必须能被机器复核——能写 `verify` 就写：
   ```js
   { type:"calc", title:"…", inputs:[{name:"v₀",value:"20 m/s"},{name:"θ",value:"45°"}],
     outputs:["R = 40.8 m"],
     verify:{ expr:"v0^2*sind(2*theta)/g", value:"40.8", unit:"m", tol:0.1, map:{v0:20, theta:45, g:9.8} } }
   ```
   `map` 给出符号取值；`expr` 支持 `+ - * / ^ ( )`、`sqrt/exp/ln/log10/abs/min/max`、常量 `pi`/`e`。
   **三角函数默认弧度**：`sin/cos/tan` 用弧度，`sind/cosd/tand` 用**度数**（角度量一律用 `sind` 等）。
   一元负号先作用于最近的数（`-2^2 = 4`），要 `-(2^2)` 请写括号。
   `verify-numbers.mjs` 会用自写的解析器重算（不用 eval），符号写漏会直接报错。
   写不了 `verify` 的（如需要查表）必须在 `note` 里写清"如何手工核对"。
3. **数量级估算**：核心课程每讲至少一处"先估个量级"的演示（用 `concept` 或 `calc`），
   培养"答案合不合理"的判断力。估算要写出：已知量 → 近似 → 结果 → 与常识对照。
4. **量纲检查**：推导 `steps` 里至少一步显式做量纲检查（写成「左边 m/s²，右边 N/kg = m/s²，一致」）。
5. **直观与严格分开**：先物理图像，再定量；明确指出"哪里是近似、近似在什么条件下失效"。
6. **术语中英并列**（首次出现）：如「动量（momentum）」「熵（entropy）」「简正模（normal mode）」。
7. **数值必须带单位与有效数字**：写 `40.8 m` 而不是 `40.8`；有效数字要与输入匹配，不要写 8 位。
8. **常量以 `app/constants.js` 为准**：不要凭记忆写数值；CODATA 表就摆在那里。
9. **禁止的词**：显然、易得、众所周知、不言而喻。换成"可以验证""代入试试""下面给一个例子"。
10. **仿真的诚实标注**：用了 `simlab` 的讲，要在 `pitfall` 或 `note` 里说明"仿真用的是数值积分/线性模型，
    与真实实验的差别在哪"（例如忽略空气阻力、忽略弹簧质量）。

### 自足性（硬要求）

`node tools/audit-independence.mjs` 的目标是**跨课指引 = 0**。所以：

- **禁止**「去数学站学微积分」「先做 cs 站的 xx」「参见《数学分析》」这类跨站/跨课指路；
- 本讲用到的数学操作，**在用到的那一句里用一句话解释清楚**（例："这里要对 x² 求导，即求它的变化率 2x"）；
- 系统性的数学训练放在《数学物理方法（一）（二）》里，但那两门课也**不得反向要求**读者先学别的课；
- 允许同一门课内的前向指引（「不熟的话先看本课第 2 讲」）。

## 6. Quiz（测验题）

```js
{ id:"mech-newton-laws-q1", type:"single", q:"…", options:["A","B","C","D"], answer:1, why:"…" }
{ id:"mech-newton-laws-q2", type:"multi",  q:"…", options:[...], answer:[0,2], why:"…" }
{ id:"mech-newton-laws-q3", type:"fill",   q:"…（填数字）", answer:["9.8"], numeric:true, tol:0.15, unit:"m/s²", why:"…" }
{ id:"mech-newton-laws-q4", type:"order",  q:"把解题步骤排成正确顺序", items:[...], answer:[2,0,1], why:"…" }
```

硬性要求：

- `why` 必填，写清"为什么对 + 干扰项错在哪"，**不少于 30 字**。
- `id` 全局唯一并以课程前缀开头（如 `mech-`、`pz-`）。
- 每课至少：**1 题概念辨析 + 1 题计算/推导 + 1 题易错点**；建议再加 1 题综合应用。
- **数值题用 `type:"fill"` + `numeric:true` + `tol`**（引擎已支持数值判分，`tol` 必填），
  并在 `unit` 里写单位——判分时会提示单位。
- 单选 `answer` 是整数索引；多选是升序数组；`order.answer` 是 `items` 的下标排列。

## 7. Flashcards（闪卡）

```js
flashcards: [
  { id:"mech-newton-laws-f1", kind:"定律", front:"牛顿第二定律的数学形式与成立条件？",
    back:"$\\vec{F}=m\\vec{a}$。成立条件：惯性系、质点、v ≪ c。$\\vec{F}$ 是**合力**，不是某一个力。",
    why:"最常见的错：把某一个力当成合力代入。" },
  { id:"mech-newton-laws-f2", kind:"常量", front:"标准重力加速度 g 的值与实测范围？",
    back:"定义值 9.806 65 m/s²；地表实测约 9.78~9.83 m/s²，做题无特别说明可用 9.8。" }
]
```

- `kind ∈ {公式, 常量, 量级, 定律, 单位, 方法, 概念, 实验}`（决定卡片图标）。
- 每讲 **6~12 张**；`back` 要"一句话定义 + 例子/条件"，不要只写一个词。
- 优先做**必须张口就来**的东西：公式、常量与量级、定律的成立条件、单位换算、实验方法。
- 闪卡用 SM-2 排程（`app/cards.js`），所以宁可少而准，不要灌水。

## 10. W2 模型契约（17 个新仿真模型）

本节的每个模型都规定了 **精确的 `params` 名字、`plots` 键名、读数与必做自检的解析期望值**。
模型作者照此实现，课程作者照此写 `config`——两边对不上会被 `validate-curriculum.mjs`（模型名/参数名/曲线名）
与 `verify-simlab.mjs`（物理不变量）当场抓住。

**通用约定**

1. 加载时**不得触碰 DOM**；不得使用 `Math.random`（需要随机数就用文件内自带的**带种子 PRNG**，保证可重复）。
2. 自检的 `expect` 必须是**独立解析推出的值**（写在注释里给出公式），不能是"跑一遍看结果填进去"。
3. 数值单位尽量回到 SI，但允许为可读性引入无量纲化（要在 `info` 里说明）。
4. `plots[].key` 与 `compute().series` 的键名必须一致；`extra.lines` 用于"一张图多条独立曲线"（见 §3.1.1）。

### 10.1 `simlab-models-thermal.js`（热学与统计，4 个）

| 模型 | params（名字 : 单位, 默认, 范围） | 输出 | 必做自检（expect 为解析值） |
|---|---|---|---|
| **`kinetic-gas`** 麦克斯韦速率分布 | `T` : K, 300, 50~2000；`M` : g/mol, 28, 1~200 | `plots:["f"]` 横轴速率 v (m/s)，纵轴分布 f(v)；`info`: v_p、v̄、v_rms | ① 分布峰值位置 = √(2RT/M)（默认 300 K、28 g/mol → **422.098 m/s**，相对容差 1e-3）；② v̄ = √(8RT/πM) = **476.288 m/s**；③ v_rms = √(3RT/M) = **516.963 m/s**；④ 归一化 ∫f dv = 1（梯形积分，容差 1e-4） |
| **`thermo-cycle`** 卡诺循环 p–V 图 | `n` : mol, 1, 0.1~5；`T1` : K, 600, 300~1500；`T2` : K, 300, 100~1000；`V1` : m³, 0.01, 0.001~0.1；`r` : 等温膨胀比, 2, 1.2~5 | `plots:["p"]` 横轴 V (m³)；`info`: η、Q1、Q2、W、四个状态点 | ① η = 1 − T2/T1 = **0.5**；② Q1 = nRT1 ln r；③ W = Q1 − Q2 = nR(T1−T2) ln r；④ 循环闭合（末点与起点 V、p 相对偏差 < 1e-9）。绝热步用 V₃ = V₂(T1/T2)^(1/(γ−1))，γ = 1.4 |
| **`entropy-mixing`** 微观态数与熵 | `N` : 分子总数, 20, 4~60 | `plots:["W"]` 横轴左半分子数 k，纵轴微观态数 C(N,k)（可用对数纵轴数据）；`info`: W_max、k_max、S_max = k_B ln W_max、σ_k | ① W 的极大值在 k = N/2（N 取偶）；② Σ_k C(N,k) = 2^N（相对容差 1e-9）；③ 分布的方差 = N/4（容差 1e-9）；④ N = 60 时 ln W_max 与斯特林式 (N ln2 − ½ln(πN/2)) 相对偏差 < 1e-3 |
| **`random-walk`** 随机游走与扩散 | `N` : 步数, 100, 10~2000；`n` : 游走者数, 200, 10~2000；`p` : 向右概率, 0.5, 0.05~0.95；`seed` : 种子, 1, 1~9999 | `plots:["msd","theory"]` 横轴步数 t；`extra`: 末态位移直方图（`x` 为区间中心、`y` 为计数）；`info`: 实测⟨x²⟩、理论值、扩散系数 D | ① 理论 ⟨x²⟩ = 4Npq + N²(p−q)²（q = 1−p）：p = 0.5、N = 100 → **100**；p = 0.3、N = 100 → **1684**；实测相对偏差 < 5%；② **同 seed 两次运行结果完全一致**（证明没用到 `Math.random`） |

### 10.2 `simlab-models-em.js`（电磁学，5 个）

## 11. W3 模型契约（15 个新仿真模型）

与 §10 同样的约定：**参数名、曲线名、自检的解析期望值都是契约**。
本波新增一种参数形式：**枚举参数**（用于"选哪一种映射 / 哪一种统计"这类分类型选择）。

```js
params: {
  kind: { label: "映射 f(z)", type: "enum", options: ["z²", "1/z", "e^z", "√z"], def: 0 }
}
```

- 枚举参数的取值是**选项下标（从 0 开始）**，界面上渲染成下拉框；
- 模型内部用 `SIM.opt(options, p.kind)` 取选项名（越界会自动夹住）；
- 课程 `config.params.kind` 只能写 0 ~ options.length-1 的整数（校验器会报错）。
