# 阅读计划契约（READING-PLAN-SPEC）

本文件规定 `data/reading-*.js` 的**唯一格式与质量约定**，以及它们如何被 `app/app.js` 渲染。

来源：`node tools/validate-reading.mjs` 必须 0 错误。

---

## 0. 三条硬原则（比格式更重要）

### 原则 A：只推荐你能负责任地推荐的译本

推荐译本会直接影响读者能不能读下去——**选错译本会白白增加难度**。因此：

1. **只写你有把握的译本**。中国读者能拿到的经典汉译名著译本大多稳定（见 §3 的"高置信清单"，
   例如柏拉图《理想国》郭斌和/张竹明译、康德三大批判邓晓芒或李秋零译、黑格尔《精神现象学》
   贺麟/王玖兴译、亚里士多德《形而上学》吴寿彭译、《论语》杨伯峻译注等），这些可以放心写。
2. **凡是你不确定译者、出版社或版次的，就不要写具体版次**，改写 `zh: "《书名》，中译本（请按手边版本选）"`，
   并用 `tip` 说明选择要点（如"选带详细注释的版本""避免改写的缩写本"）。
3. **绝对不允许编造**译者名、出版社名、ISBN、丛书名。宁可少写，不可编。
4. 若某书**没有通行中译**或**强烈建议读原文/英译**，就把 `zh` 写成 `"—"`，并在 `tip` 里说明原因与
   可用的英文版本类型（如"建议用 Cambridge Texts 系列"这种**系列名**，不要编具体版次页码）。

### 原则 B：难度必须诚实分级

每一本都要给 `level`（1~4）——**这是深度与所需准备的标记，不是时间承诺**。
本课程**不写任何时间线**（不写"要花几周""读完要多久"），所以难度必须靠 `level` 说清楚：
把难书标简单会让读者卡死，把易书标难会让他不敢开始。

| level | 含义 | 判断依据 |
|---|---|---|
| 1 | 入门，可直接读 | 面向大众的导论、原典的注译本（有逐句解释） |
| 2 | 中等，需要耐心 | 原典本身但篇幅适中、论证清楚；或较深的二手研究 |
| 3 | 困难，需要准备 | 体系性大书（三大批判、《精神现象学》）、密集的技术论证 |
| 4 | 极难，需同伴或课程 | 需要专门训练才能独立推进（《纯粹理性批判》原文精读、哥德尔证明、晚期海德格尔） |

### 原则 C：说清"为什么读它"和"读不下去怎么办"

每本书的 `why` 必须回答"它在整个学习路径里承担什么功能"（不是复述内容简介）。
**轨迹里必须有"过渡书"**：level 4 的书前面要有一本 level 1~2 的梯子（例：读《纯粹理性批判》前先读
一本可靠的康德导论），并在 `ladder` 字段指出这本梯子是哪一本的 id。

## 1. 文件格式（硬性）

每个阅读轨迹一个文件：`data/reading-<slug>.js`，**无 BOM 的 UTF-8**，内容**只有一条**
`window.READING_PLANS.push({...});`。禁止 `import`/`export`/`require`/函数/模板字符串/反引号/LaTeX。

```js
window.READING_PLANS.push({
  id: "reading-western",              // 与文件名一致
  title: "西方哲学史主线",
  icon: "🏛",
  blurb: "一句话说明这条线带你走完什么，以及学完能达到什么程度。",
  intro: "2~4 段导语（markdown 字符串，用 \\n\\n 分段）：这条线为什么这么排、怎么用、最容易在哪一步放弃。",
  stages: [ /* 见 §2 */ ]
});
```

`stages` 建议 4~6 个（按阶段划分，**不要用"第一年/第二年"这类时间轴命名**，
改用主题或层次，如"打地基与古希腊""中世纪与近代开端"）。

> **本课程不设时间线**：轨迹级**不要写 `weeks`**，书目级也**不要写 `weeks`**。
> 校验器会把它们判为错误。理由：本课程只对质量有要求——不告诉读者"这条线要走几年"。
> 顺序与深浅由 `stages` 的排列和每本书的 `level` 表达，不用时间表达。

## 2. Stage 与 Book

```js
{
  title: "打地基与古希腊",
  goal: "这一阶段结束时你应该能做到什么（可检验，不要写'有所了解'）",
  books: [
    {
      id: "w-plato-republic",          // 全局唯一，见 §4 命名规则
      author: "柏拉图",
      title: "《理想国》",
      zh: "郭斌和、张竹明 译，商务印书馆（汉译世界学术名著丛书）",   // 译本推荐；无把握按原则 A 处理
      en: "Republic, trans. G.M.A. Grube, rev. C.D.C. Reeve (Hackett)",  // 可选：英译建议（可写系列名）
      level: 2,
      why: "为什么在这条线的这个位置读它：它承担什么功能、读它能拿到什么、不读会缺什么。",
      focus: ["读的时候重点盯什么（3~5 条，具体到卷/章/论证）"],
      lessons: ["philo-ancient-3"],     // 关联的本站课程 id（可多个；必须真实存在）
      ladder: "w-kant-intro",           // 可选：读它之前先读哪本（必须是本文件内的 book id）
      tip: "可选：版本选择、读法提示、常见卡住的地方与应对"
    }
  ]
}
```

硬性要求：
- 每个 stage 至少 3 本，每条轨迹合计 **20~45 本**。
- `lessons` 里的每个 id 必须真实存在于 `data/philo-*.js`（校验器会检查）。
- `ladder` 必须指向本文件内已存在的 book id（校验器会检查，且不允许成环）。
- `focus` 至少 3 条。
- 每条轨迹里 **level 4 的书不超过 25%**，且每本 level 4 都要有 `ladder`。
- 必须至少包含 3 本**非原著**（导论、研究、工具书），因为自学者最缺的是梯子。
- **不得出现任何时间字段**：轨迹级与书目级都不写 `weeks`（校验器会报错）。

## 3. 高置信译本清单（可放心使用）

以下译者与出版社组合在中国读者中稳定可获得（**仅列我们有把握的**）：

- 柏拉图：《理想国》郭斌和、张竹明译，商务印书馆；《申辩篇》等早期对话，王太庆译，商务印书馆
- 亚里士多德：《形而上学》吴寿彭译，商务印书馆；《尼各马可伦理学》廖申白译，商务印书馆
- 奥古斯丁：《忏悔录》周士良译，商务印书馆
- 笛卡尔：《第一哲学沉思集》庞景仁译，商务印书馆
- 洛克：《人类理解论》关文运译，商务印书馆
- 休谟：《人类理解研究》关文运译，商务印书馆
- 康德：《纯粹理性批判》邓晓芒译/李秋零译（后者见《康德著作全集》，中国人民大学出版社）；
  《实践理性批判》《判断力批判》邓晓芒译，人民出版社；《道德形而上学奠基》苗力田译
- 黑格尔：《精神现象学》贺麟、王玖兴译，商务印书馆；《小逻辑》贺麟译，商务印书馆
- 维特根斯坦：《哲学研究》陈嘉映译，商务印书馆/上海人民出版社
- 罗尔斯：《正义论》何怀宏、何包钢、廖申白译，中国社会科学出版社
- 伽达默尔：《真理与方法》洪汉鼎译，商务印书馆
- 《论语》杨伯峻《论语译注》，中华书局；《孟子》杨伯峻《孟子译注》，中华书局；
  《老子》陈鼓应《老子今注今译》，中华书局/商务印书馆；《庄子》陈鼓应《庄子今注今译》，中华书局
- 《坛经》郭朋《坛经校释》，中华书局
- 马克思恩格斯：人民出版社《马克思恩格斯选集》/《马克思恩格斯文集》

**这份清单之外的一切，按原则 A 保守处理。**

## 4. book id 命名规则

`<轨迹前缀>-<作者或主题>-<短名>`，全小写 kebab-case，全局唯一。
轨迹前缀：西方线 `w-`、中国线 `c-`、问题线 `p-`。

例：`w-plato-republic`、`c-zhuangzi`、`p-kant-groundwork`。

---

## 5. 校验器会检查

`node tools/validate-reading.mjs` 检查：
文件格式（无反引号/BOM/模块语法/真实换行）、id 唯一、`lessons` 引用是否真实存在、
`ladder` 是否有效且无环、`level` 是否在 1~4、是否残留任何时间字段（`weeks`）、
每 stage 至少 3 本、总数 20~45、level 4 占比与 ladder 配备、
`focus` 至少 3 条、是否含至少 3 本非原著、禁用词
（显然/易得/众所周知/不言而喻/读者自证/显而易见/毋庸置疑）。

---

## 6. 写作质量要求（会被人工抽查）

1. **不要写成书目清单**。`why` 要说清这本书在路径中的**功能**：
   它是梯子、是主攻对象、还是查证用的工具书。
2. **要有取舍**。可以明确说"这本书不必通读，只读某几卷"——这比让读者硬啃更有价值。
3. **诚实说明代价**：读这本书会花多久、会在哪里卡住、卡住了该怎么办（找哪本梯子、跳过哪一部分）。
4. **中文为主**，人名与书名首次出现附原文。
5. 简体中文。
