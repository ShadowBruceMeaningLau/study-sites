# 哲学本科 · 互动学习站

一个**离线、零依赖**的哲学本科自学系统。双击 `index.html` 就能用，不需要联网、不需要安装任何东西，
学习进度只存在你自己的浏览器里。

> 想直接要**一个文件**？用 `philosophy-standalone.html`：它把课程内容、样式与引擎全部内联在一个
> HTML 里，拷到 U 盘或发给别人都能直接打开。

---

仍需注意的两点（诚实标注）：

- **「有覆盖」不等于「有独立课程」**。少数条目是"仅提及"级别：**归纳逻辑与决策论**
  （现只在认识论里讲了绿蓝悖论与贝叶斯）、**环境伦理 / 生态哲学**（现只讲了气候正义与代际正义）、

  不是本科四年的替代品。**深度请走精读轨迹。**

## 2. 五种训练方式（这是它和"看视频课"的区别）
| 工具 | 练什么 |
|---|---|
| 📜 **原著精读** | 直接读柏拉图、笛卡尔、休谟、康德、罗尔斯、王阳明的原文选段，点击高亮看逐句注释与常见误读。 |
| 🧔 **苏格拉底式提问** | 程序扮演苏格拉底追问你：你选一个回答，它立刻告诉你这个回答站得住、有漏洞还是明显错误，并继续追问。**目的不是把你堵死，而是逼你把主张说精确。** |
| 🧩 **论证重构** | 给你几句原文，你判定哪些是前提、哪句是结论、哪句是无关干扰；再对照形式化、有效性、可靠性与「关键缺口」。 |
| 🃏 **间隔重复闪卡** | 术语/人物/论证/立场四类卡片，按 SM-2 简化版调度：记得越牢出现越晚，「完全不会」10 分钟后重来。 |
| ✍️ **写作训练** | 题目 + 构思清单 + 建议结构 + 评分细则（Rubric，权重合计 100%）+ 范例片段 + 常见失分点，草稿自动保存、可逐条自查。 |

另外还有：错题本、智能复习、学习报告（各课掌握度 / 薄弱环节 / 14 天热力图 / XP 与连续天数）、
术语表（166 条，中英/希腊/拉丁/德文原词并列）、全局搜索。

## 2.5 精读轨迹：从课程走向真正的深度

**说清本站的边界**：17 门课 / 85 讲给你的是一张**问题地图**与一套**方法训练**
（读原著、拆论证、写论文）。它替代不了大学，也替代不了**把整本书读完并被人反驳**这个环节。
每门课只有 5 讲，而真实一门专业课是一整个学期——所以它是"地图 + 教练"，不是"全部"。

**精读轨迹（📚 侧栏入口）** 就是补这一段用的。每条轨迹给出：

- **读哪些书、什么顺序**（分阶段，每阶段有可检验的目标）
- **难度分级 L1~L4**：入门可直接读 → 中等需耐心 → 困难需准备 → 极难需同伴或课程
- **推荐哪个中译本**（并说明怎么挑版本；没有可靠中译的就注明读英译）
- **每本书在路径里承担什么功能**：是梯子、主攻对象还是工具书
- **读的时候重点盯什么**（具体到卷/章/论证）、**会在哪里卡住**、**卡住了先读哪本梯子书**（`ladder`）
- **对应本站哪几讲**：课时页底部会自动显示「读完这一讲，接着读这些」

三条轨迹：

| 轨迹 | 组织方式 | 适合 |
|---|---|---|
| 🏛 **西方哲学史主线** | 按时间：古希腊 → 中世纪与近代 → 德国古典 → 十九世纪 → 二十世纪至今 | 想要完整时间坐标 |
| 🀄 **中国哲学主线** | 按时间：先秦 → 两汉隋唐（含佛教）→ 宋明理学 → 明清之际 → 近现代 | 想沿中国思想史走一遍 |
| 🎯 **问题导向深挖线** | 按分支：知识论 / 形而上学 / 伦理学 / 政治哲学 / 心灵与语言 | 想在一个问题上达到能与人对话的程度 |

**建议用法**：先把课程走一遍拿到地图与方法 → 再选**一条**轨迹死磕 → 同时进入真实的智识共同体
（读书会、线上研讨、旁听大学课程、写作投稿）。三个最常见的失败点，轨迹里都标了应对：
① 一上来就读 level 4 的体系大书（先读 `ladder` 指的那本梯子）；② 想通读每一本（很多书只需读指定几卷）；
③ 只读不写（读完一本就写一篇，用本站的写作训练当题库）。

数据格式见 `READING-PLAN-SPEC.md`，校验用 `node tools/validate-reading.mjs`。

### 零基础读者的两个兜底功能

1. **🖍 生词标注**（顶栏开关）：打开后，正文里所有**已学术语**自动加虚线下划线，**点一下直接弹出解释**，
   不用离开当前页去翻术语表。标注来源是一张合并后的术语底表：**443 条、全部带解释**
   （166 条术语表 + 565 张闪卡去重）。熟悉内容后可以关掉。
2. **🔍 查术语**（顶栏按钮）：遇到完全不认识的词（哪怕底表里没有），输入即可查；
   没有精确匹配时会列出相近条目。

另外，每讲的第一块都是**生活类比**（例如用辣椒素与 TRPV1 受体讲「美为什么不是对象里的零件」、
用孩子问打雷讲「神话解释与自然解释之别」），每段原著都有**逐句注释**，
`need` 字段会写明学这一讲之前需要会什么、零基础应该先看哪一讲。

## 3. 怎么用

```
双击 index.html               # 就用这个（file:// 直接可用，无需服务器）
双击 start-philosophy.cmd     # Windows 下更省事；装了 Node 的话会顺便起服务器，支持手机访问
```

快捷键：`/` 搜索 ｜ `Ctrl+Enter` 标记本讲已掌握 ｜ `Alt+←` / `Alt+→` 上一讲 / 下一讲

### 用手机 / 平板看

双击 `start-philosophy.cmd` 即可。它会在本机起一个静态服务器（端口 **8126**），
并把**手机可以直接打开的局域网地址**打印在窗口里，形如：

```
手机 / 平板（需与本机连同一个 WiFi）:
  http://192.168.0.107:8126/index.html   [WLAN]
```

把那一行照抄进手机浏览器就行。三个要点：

- **手机要与这台电脑连同一个 WiFi**（地址里的 `192.168.x.x` 是电脑在局域网里的地址，
  外网或者别的网络都打不开）。
- **手机和电脑共用同一份学习进度**：都连这台服务器时，两边读写同一份进度文件（存在本站 `.progress/` 里），
  在电脑上做到第 5 讲，手机上接着做就行。
- **不用的时候把那个黑窗口关掉**，服务就停了；也可以按 `Ctrl+C`。
  安全提示：同一个网络下的设备都能打开这个站（里面没有隐私数据，但知道这一点比较好）。

没有装 Node.js 时，脚本会退回到直接打开文件——那样只有本机能看，手机连不上。

**其它两个入口**：`philosophy-standalone.html` 是单文件版（5.2 MB，把全部课程打包进一个 HTML），
拷到 U 盘或发给别人都能直接打开，也不需要服务器。

**想用手机连别的站**：根目录的 `start-all.cmd` 一次起**四个站的服务**（各占一个端口：
计算机 8123、数学 8124、物理 8125、哲学 8126），并在同一个窗口里把四个站的本机地址与手机地址全部列出来。
单站启动脚本（`cs\start.cmd`、`math\start-math.cmd`、`physics\start-physics.cmd`）同样带 `--lan`。

**学习路线建议**（首页也写了）：哲学导论 → 逻辑工具 → 古希腊 → 中世纪与德国古典 → 近代 →
马克思主义哲学 / 认识论 / 形而上学 / 伦理学 / 政治哲学 / 社会哲学 → 当代 / 逻辑元理论 / 中国线 → 专题。
固定动作只有一条：**每一讲都要自己写出理由**（做论证重构、答苏格拉底追问、写完写作训练）。

## 5. 改内容 / 加课程

1. 读 `PHILO-CONTENT-SPEC.md`（**尤其 §0 的三条哲学站特有原则**：讲论证不讲名词、钢人原则、区分文本与重构，
   以及 §2 关于「禁止反引号 vs 标注公式」的澄清）。
2. 新建 `data/philo-<slug>.js`，格式为单条 `window.COURSE_PACKS.push({...})`。
   注意：**不要用反引号**；多行文本用 `\n\n` 在同一行内连接（字符串里出现真实换行会让整个文件无法解析）。
3. 把课程 id 加进 `app/app.js` 顶部的 `ORDER` 数组（决定展示顺序）。
4. 生成页面并自检：

```powershell
node tools/build.mjs                  # 重新生成 index.html 与单文件版
node tools/validate-curriculum.mjs    # 结构校验（必须 0 错误）
node tools/fix-content.mjs            # 机械清理：反引号 / 禁用词（可先加 --dry 预览）
node tools/audit-zero-basis.mjs       # 零基础审计（首现未解释应趋近 0）
node tools/smoke-test.mjs             # 冒烟测试：数据完整性 + 学术诚信 + 产物 + 真实浏览器渲染
```

### 四个自检工具各查什么

- **validate-curriculum.mjs**：文件格式（无反引号/BOM/多行字符串/模块语法）、id 唯一、`close` 注释是否为原文逐字子串、
  `socratic` 决策树的 `next` 是否成环且给读者留出路、`arguments` 是否恰好一个结论、
  `rubric` 权重是否合计 100%、禁用词、题型答案索引、以及每讲是否配齐精读/苏格拉底/推演。
- **fix-content.mjs**：把违反契约的机械问题批量修掉（反引号→「」、禁用词→可验证的说法），并报告疑似模块语法。
- **audit-zero-basis.mjs**：输出「首现未解释」与「后续仅使用」两个数字（沿用本站既有的
  `ZERO-BASIS-STANDARD.md` 口径）。误报可加进脚本顶部的 `FALSE_POSITIVE` 表。
  当前值：首现未解释 1（政治哲学第 3 讲对「审议民主」的前向引用，正文已指明「第 5 讲会展开它」，
  属契约允许的写法）。
- **verify-truthtables.mjs**：用递归下降解析器**独立重算**逻辑课 `tablelab` 里的每个真值表格子
  （不依赖课程数据自洽性）。当前：60 格全部一致；8 格量词公式超出命题逻辑求值器，属人工核对范围。
- **remove-time.mjs**：把内容里的时间字段清掉（`est`、`weeks`、`hours`）。
  本课程**只对质量有要求**，不写"这一讲要花多久""这条线要走几年"——那是时间表，不是学问。
- **coverage-check.mjs**：对照哲学本科通行课程表检查覆盖度（见上），用于发现「还缺哪一块」。
- **validate-reading.mjs**：校验精读轨迹（书目的 `lessons` 是否指向真实讲次、`ladder` 是否成环、
  level 4 占比与梯子配备、是否含足够的非原著梯子书、是否残留任何时间字段）。
- **lex.mjs**：共用的源码词法扫描器（正确区分字符串、注释、正则与英文撇号），
  被两个校验器共用——避免三份拷贝各自漂移（历史上曾因英文撇号 `Oxford World's Classics`
  造成误报）。
- **smoke-test.mjs**：跨课 id 一致性、闪卡 `where` 引用可达、**学术诚信检查**
  （每个精读块是否标了作者与章节号、凡非逐字引用是否声明了「内容概述，非逐字引文」）、
  `index.html` 是否引用了全部课程、单文件版是否真的自包含，
  并用 Edge/Chrome 无头模式**实际渲染页面**验证应用启动。

## 6. 已知边界（重要）

- **写作训练无法自动判分**。它给的是题目、Rubric 与范例，最终判断要你自己做——这是设计选择，不是缺陷。
- **哲学内容由 AI 生成，未经同行评审**。`close` 块中的原著引文都标注了出处；凡不是逐字原文的，
  都在 `note` 里注明「此处为内容概述，非逐字引文」。**引用前请以纸质/权威版本核对原文。**
- **政治哲学部分保持学术中立**：各立场（自由至上主义、社会主义、保守主义等）均按最强版本呈现，
  不暗示任何立场是"正确答案"。
- 进度数据存在浏览器 `localStorage`。**换浏览器/清理缓存会丢**，请用右上角「💾 数据」导出备份。
- `file://` 打开时剪贴板 API 可能受限，属浏览器安全策略。

本站与同目录的 `math/`、`cs/` 两个学习站共用同一套引擎范式（`data/*.js` 内容包 + 零依赖 `app/`，
`file://` 直接可用）与同一份零基础标准（`../ZERO-BASIS-STANDARD.md`）。三站互不依赖，可独立使用。
