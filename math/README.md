# 基础数学 · 本科互动学习站

一个**零依赖、离线可用**的数学系本科基础课程自学程序：双击 `index.html` 就能在浏览器里按培养方案学习，
包含严格定义与证明讲解、可点运行的数学实验、随堂测验与错题本，学习进度自动保存在本地。

> 面向：想系统学数学系本科基础主干的人（在校生、跨专业自学者、想补严格性的人）。
> 编排原则：**直观 → 严格定义 → 证明 → 计算 → 反例**，五步缺一不可。

---

## 1. 快速开始

- **方式 A（最简单）**：双击 `index.html`，用 Chrome / Edge / Firefox 打开，全部离线可用。
- **方式 B（推荐）**：双击 `start-math.cmd`，在 `http://127.0.0.1:8124/` 起本地服务器并自动打开浏览器。

> `start-math.cmd` 内部只写 ASCII 英文提示：cmd.exe 按字节解析批处理，中文容易把命令行撕裂
> （会出现 `'evel' 不是内部或外部命令` 这类报错）。中文说明以本文件为准。

## 3. 每一讲长什么样

1. **学习目标**：一句话说明学完能做到什么。
2. **核心讲解 / 几何直观 / 证明骨架**：先给直观，再给严格表述，并指出"直观不能代替证明"的地方。
3. **代码示例**：Python 数值实验（如用程序验证 ε-N、黎曼和收敛、幂迭代），可一键复制。
4. **手算演练**：给条件自己先算，再点「显示答案」核对。
5. **🧪 交互实验**：页面上单步运行数学过程，共 6 类组件：
   - `单步执行器`：ε-N 验证、黎曼和逼近、泰勒逐项、高斯消元、幂迭代、施密特正交化、
     大数定律累计频率、贝叶斯后验更新、中心极限定理采样、留数计算、皮卡迭代、康托尔集构造……
   - `寻路实验`：带权网格上的最短路（讲梯度、范数、保守场路径无关、良序与博弈）；
   - `位模式实验`：浮点误差与有效数字（讲数值分析时用）；
   - `页面置换 / 调度甘特图`：讲有限窗口、迭代收敛速度对比时用。
6. **易错点**：证明里最容易跳步、定义最容易记错的地方。
7. **随堂测验 + 解析**：单选 / 多选 / 填空 / 排序四种题型，答错自动进错题本。

## 4. 进度、错题本与复习

- **左侧导航**：点侧边栏任意条目切页；条目是真正的链接（`<a href="#/...">`），支持中键新标签与键盘操作。
- **自动记录**：进入一讲即标记"进行中"；测验成绩与"标记已掌握"写入 localStorage（键名 `math-learn:v1`，与 CS 站互不干扰）。
- **错题本（📕）**：按错误次数排序，可跳到原课重做或导出 JSON。
- **智能复习（🔁）**：优先抽错题，其次正确率低的课，每次 8 题；答对自动移出错题本。
- **数据备份（💾 数据）**：导出/导入 JSON，可跨设备迁移。
- **快捷键**：`/` 搜索，`Ctrl/⌘ + Enter` 标记掌握，`Alt + ←/→` 上一讲/下一讲。

## 6. 数学公式怎么写的（KaTeX）

公式写在 `$...$` 里，由 **KaTeX** 渲染成出版级排版（分式、根号、求和、积分、矩阵、上下标都正常）：

```js
md: "当 $n \\to \\infty$ 时 $\\frac{1}{n} \\to 0$。"
md: "$$ \\int_0^1 x^2\\,dx = \\frac{1}{3} $$"     // 独立成行的大公式
```

- **完全离线**：KaTeX 就在 `vendor/katex/`（约 520 KB，含 20 个字体文件），不联网、不用 CDN，
  双击 `index.html` 走 `file://` 也能正常显示（已用无头浏览器验证字体确实加载成功）。
- **双引擎兜底**：万一 `vendor/katex/` 被删掉，`app/mathrender.js` 里还有一个纯 CSS 的
  TeX 子集渲染器会自动顶上，公式仍然看得懂，不会白屏。
- **不会误判**：正文里的 `echo $?`、SQL 的 `$1`、`Java 的 Outer$1.class` 这类美元符号不会被当成公式
  （扫描器要求公式首字符不是数字、首尾无空格、公式内的中文必须写在 `\text{}` 里）。
- **重新下载 KaTeX**：`node tools/fetch-katex.mjs`（仅此一步需要联网，之后永久离线可用）。
- **改写规范与字段表**：见 `MATH-FORMULAS.md`；已改好的样板见 `data/math-analysis-1.js` 第 1 讲。
- 自检页：浏览器打开 `tools/math-demo.html`，一次看完 10 类公式与「不该被当成公式」的反例。
